# 프로젝트 규칙

## 기술
| 항목 | 선택 |
|---|---|
| 프론트 | React 19.3, Vite 8 |
| 패키지 관리자 | npm |
| 동작 테스트 | Vitest 5, Testing Library 16 |
| 화면 테스트 | Playwright 1.65 |

## 폴더
| 무엇 | 폴더 |
|---|---|
| 학생 코드 | todo-app |

## 실행
- 설치: cd todo-app, npm install
- 프론트: cd todo-app, npm run dev (5173)
- 테스트: cd todo-app, npm test
- 빌드: npm run build
- 연결: todo-app/node_modules

## 캡처
| 종류 | 주소나 명령 |
|---|---|
| web | http://localhost:5173 |

## 디자인
- 일반 CSS 파일 하나
