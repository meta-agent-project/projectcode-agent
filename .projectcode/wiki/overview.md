# 할 일 앱으로 배우는 순수 React

대상: HTML, CSS, JS 기초를 아는 학생
결과물: 할 일을 추가, 완료, 삭제, 수정하고 골라 보는 웹 앱

| 번호 | 장 | 종류 | 배울 것 | 상태 | task | 사진 |
|---|---|---|---|---|---|---|
| 1 | project-setup 프로젝트 뼈대 | 기능 | Vite 프로젝트 구조, 실행과 테스트 방법 | 완료 | 4 | 5 |
| 2 | todo-list 할 일 목록 보여주기 | 기능 | 컴포넌트, JSX, map으로 목록 그리기, key | 완료 | 2 | 3 |
| 3 | todo-add 할 일 추가 | 기능 | useState, 입력값 state로 기억하기, form 제출 이벤트 | 진행 중 | 3 | 0 |
| 4 | todo-toggle 완료 체크 | 기능 | map으로 새 배열 만들어 state 바꾸기, 조건에 따른 class | 대기 | 0 | 0 |
| 5 | todo-delete 할 일 삭제 | 기능 | filter로 새 배열 만들어 지우기 | 대기 | 0 | 0 |
| 6 | todo-components 컴포넌트 나누기 | 리팩터 | props, 함수 props, state는 부모에 두기 | 대기 | 0 | 0 |
| 7 | todo-edit 할 일 수정 | 기능 | 조건부 렌더링, 자식 컴포넌트 안의 state | 대기 | 0 | 0 |
| 8 | todo-filter 골라 보기 | 기능 | state에서 계산한 값, 선택된 버튼 표시 | 대기 | 0 | 0 |

## 미룬 것
- 남은 할 일 개수 표시: 장 정하지 않음
- 끝난 일 모두 지우기: 장 정하지 않음

## 하지 않는 것
- 서버와 fetch
- localStorage 저장과 useEffect
- react-router, 상태 관리 라이브러리
- TypeScript
- 배포
