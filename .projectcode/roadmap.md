# 로드맵

강의: 할 일 앱으로 배우는 순수 React
대상: HTML, CSS, JS 기초를 아는 학생
결과물: 할 일을 추가, 완료, 삭제, 수정하고 골라 보는 웹 앱

## 선수 지식
- HTML: form, input, button, ul, li
- CSS: 선택자, class, 기본 배치
- JS: 변수, 함수, 화살표 함수, 배열, 객체, map, filter

## 학습 목표
- 컴포넌트와 JSX
- 배열을 화면 목록으로 그리기와 key
- useState와 이벤트 처리
- 배열 state를 새 배열로 바꾸기
- props와 함수 props로 컴포넌트 나누기
- 조건부 렌더링과 state에서 계산한 값

## 장
| 번호 | 장 ID | 이름 | 종류 | 배울 것 | 상태 |
|---|---|---|---|---|---|
| 1 | project-setup | 프로젝트 뼈대 | 기능 | Vite 프로젝트 구조, 실행과 테스트 방법 | 완료 |
| 2 | todo-list | 할 일 목록 보여주기 | 기능 | 컴포넌트, JSX, map으로 목록 그리기, key | 완료 |
| 3 | todo-add | 할 일 추가 | 기능 | useState, 입력값 state로 기억하기, form 제출 이벤트 | 완료 |
| 4 | todo-toggle | 완료 체크 | 기능 | map으로 새 배열 만들어 state 바꾸기, 조건에 따른 class | 완료 |
| 5 | todo-delete | 할 일 삭제 | 기능 | filter로 새 배열 만들어 지우기 | 완료 |

## 미룬 것
- 남은 할 일 개수 표시
- 끝난 일 모두 지우기

- 서버와 fetch
- localStorage 저장과 useEffect
- react-router, 상태 관리 라이브러리
- TypeScript
- 배포
