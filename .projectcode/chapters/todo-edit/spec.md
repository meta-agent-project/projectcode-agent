# todo-edit 할 일 수정

종류: 기능
배울 것: 조건부 렌더링, 자식 컴포넌트 안의 state

## 할 일
- S1 할 일마다 수정 버튼이 있고, 누르면 그 줄만 지금 글이 든 고치는 칸과 취소 버튼으로 바뀌고, 취소를 누르면 고친 글은 버리고 원래 줄로 돌아온다
- S2 고치는 칸에서 저장을 누르거나 Enter를 치면 고친 글이 목록에 보이고 원래 줄 모양으로 돌아온다
- S3 고치는 칸이 비었거나 빈칸만 있으면 저장을 눌러도 글이 바뀌지 않는다

## 흐름
수정 클릭 -> 그 줄의 고치기 state 켜기 -> 고치는 칸 -> 저장 -> 부모의 todos 바꾸기 -> 원래 줄

## 안 하는 것
- 글을 두 번 눌러 고치기: 안 만듦
- 한 번에 한 줄만 고치게 막기: 미룸
