# project-setup 프로젝트 뼈대

종류: 기능
배울 것: Vite 프로젝트 구조, 실행과 테스트 방법

## 할 일
- S1 개발 서버를 띄우고 브라우저로 열면 할 일 제목이 있는 첫 화면이 뜬다
- S2 첫 화면은 공통 스타일로 바탕 위 가운데 카드 모양으로 보인다
- S3 테스트 명령을 실행하면 첫 화면에 제목이 보이는지 확인하는 테스트가 통과한다
- S4 포맷 명령을 실행하면 학생 코드의 모양이 한 가지로 맞춰진다
