# todo-add 할 일 추가

종류: 기능
배울 것: useState, 입력값 state로 기억하기, form 제출 이벤트

## 할 일
- S1 할 일 칸에 글을 쓰면 화면이 그 글을 기억해 칸에 보여준다
- S2 추가를 누르거나 Enter를 치면 목록 맨 아래에 그 할 일이 더해지고 칸이 비워진다
- S3 칸이 비었거나 빈칸만 있으면 추가를 눌러도 아무것도 더해지지 않는다

## 흐름
글 입력 -> 값 기억 -> 추가 -> 목록에 더하기 -> 칸 비우기

## 안 하는 것
- 같은 글 막기: 미룸
- 완료 체크: todo-toggle 장
